Built around four principles

Local First

Your commands stay on your machine. No cloud API required for core functionality.

Open Source

Built completely around open technologies and open-weight models.

Low Latency

Avoid unnecessary generation and repeated inference. Designed for speed.

Lightweight

Designed to run on normal consumer hardware with a ~1.5 GB memory target for the core intelligence.

AI chooses. Code executes.

Security and reliability are paramount. VoiceDriveOS operates within a closed action space. The AI classifies the intent, but the execution layer runs deterministic Python code.
